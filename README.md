## 👁️ About

I build and break hardware. My focus is offensive security on small, portable devices: the kind of kit you can fit in a pocket and still pop a network with. Everything here is written for **educational, defensive, and authorized testing use only.**

- 🔧 I design custom payloads and firmware for Hak5 and RaspyJack hardware
- 📡 Sub-GHz, RF, Wi-Fi, BLE, and physical-access tooling
- 🎥 I document the builds on [YouTube](https://www.youtube.com/@Hackazillarex) and [TikTok](https://www.tiktok.com/@hackazillarex) so you can follow along
